# Code de conduite

## En résumé

Ce projet est un petit outil pour la communauté Garry's Mod. La règle tient en
une phrase : **soyez corrects les uns envers les autres.**

## Ce qu'on attend

- Restez courtois, même en désaccord, même quand un bug vous a fait perdre une
  soirée.
- Acceptez qu'on ait tous des niveaux différents. Une question « bête » sur les
  `.vmt` ou sur Python est une question légitime.
- Critiquez le code, pas la personne qui l'a écrit.
- Quand vous signalez un problème, donnez les faits : ce que vous attendiez, ce
  qui s'est passé, le journal si vous l'avez.

## Ce qu'on n'accepte pas

- Insultes, harcèlement, propos racistes, sexistes, homophobes ou transphobes.
- Attaques personnelles et trolling.
- Publication d'informations privées sur quelqu'un sans son accord.
- Contenu sexuel ou violent dans les tickets, les PR ou les discussions.

## Où ça s'applique

Partout où le projet vit : tickets, pull requests, commentaires de commits, et
tout espace où quelqu'un représente le projet.

## S'il y a un problème

Signalez-le en ouvrant un ticket, ou en contactant directement le mainteneur
([@TenGoKu13](https://github.com/TenGoKu13)) si le sujet est sensible.

Les signalements sont traités sérieusement et discrètement. Selon la gravité,
la réponse va du simple rappel au blocage définitif du dépôt. La décision
appartient au mainteneur.
